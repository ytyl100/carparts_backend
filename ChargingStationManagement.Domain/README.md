Domain层包含了：

Entities：定义了所有核心业务实体，包括聚合根和普通实体

ValueObjects：定义了地址、坐标、费率等值对象

Enums：定义了所有枚举类型

Events：定义了所有领域事件

Specifications：实现了规约模式，用于复杂的查询条件组合

Interfaces：定义了领域服务接口和仓储接口

Helpers：提供了一些辅助工具类

每个实体都有完整的业务逻辑和验证规则，确保了领域模型的完整性和一致性。领域事件的使用实现了领域对象之间的松耦合通信。规约模式使得复杂的查询逻辑可以重用和组合。

这个Domain层是完全独立的，不依赖于任何外部框架，只使用了MediatR来处理领域事件。这确保了领域模型的纯粹性和可测试性。
